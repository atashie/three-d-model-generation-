2. **Medium — NaN midpoint distances can disappear and produce a false PASS.**  
   **Location:** [printed.py:1036](C:/Users/arikt/documents/github/three-d-model-generation-/src/tdmg/printed.py:1036), especially the reduction at line 1044.

   `np.argmax(dm)` selects a NaN, its comparison against `best` is false, and NaN bounds stop splitting. Python’s outer `max()` can then discard the NaN batch after an earlier finite batch. `_judged` also lacks a finite-value guard.

   ```python

   import shapely
   from unittest.mock import patch
   import tdmg.printed as p

   section = shapely.box(0, 0, 10, 10)
   alignment = p.Alignment(0, (5, 5), (128, 128))
   footprint = alignment.apply(
       shapely.box(-1, -1, 11, 11).difference(
           shapely.Point(10, 5.025).buffer(.21, quad_segs=64)
       )
   )
   edges = p.edge_gaps(section, footprint, alignment)
   with patch.object(p, "gaps",
                     side_effect=lambda pts, _: np.full(len(pts), np.nan)):
       result = p.refine_edge(section, footprint, alignment, .2, edges)

   print(p._judged(
       [dict(result, allowance_mm=.2)],
       "max_gap_mm", .025, "pair_bound_max_mm"
   )[0])
   ```

   This prints **PASS**. The actual notch-centre gap is **0.209984 mm**, against **0.2 mm**; the reported bound is only **0.184988 mm**. A failed measurement must produce UNKNOWN or an explicit measurement error, never a certified bound.
