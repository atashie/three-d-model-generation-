# Start here

This page explains what you need to know about 3D-printable files to follow the rest of the docs. It assumes you know Python and data, but not 3D modelling.

## What the project does

You give it an image. It gives back a file your printer can print, plus a report. The report says which checks passed, which failed, which could not be measured, and where every threshold came from. The tool says **PRINTABLE** only when every check required for that kind of print passes.

## The few ideas you need

**A mesh is a list of triangles.** Printable files describe the *surface* of an object as many small triangles. Each triangle has three vertices, which are points in millimetres. There is no "inside" in the file; the inside is implied by the closed surface around it.

**A printable mesh must be a closed, consistent surface.** Four properties matter:
- **Watertight, or closed:** no holes in the surface. If water could leak out, the slicer cannot tell inside from outside.
- **Edge-manifold:** every edge is shared by exactly two triangles. An edge shared by three or more triangles is "non-manifold". The 3MF standard requires this for solid objects (rule `format.3mf.edge_manifold`).
- **Vertex-manifold:** no two surfaces are pinched together at a single point. The 3MF edge rule does not catch this: two cubes touching at one corner pass it, and pass common library checks too. This project checks it separately (rule `gate.topology.vertex_manifold`).
- **Consistently oriented:** each triangle has a front side, its normal, and all of them point outward (rule `format.3mf.consistent_orientation`).

Geometry generated by AI from photos often fails all three. That is why this project has a validation gate.

**STL vs 3MF.**
- **STL** is the old format. It is just triangles: no units, no colors, no grouping. A slicer guesses that the numbers are millimetres.
- **3MF** is a zip file containing XML. It has explicit units, multiple objects, colors and materials, and metadata, and it is an ISO standard.

This project writes 3MF by default and STL only for simple single-color parts.

**A slicer turns the mesh into printer instructions.** It cuts the model into horizontal layers and plans the nozzle's path for each layer. The result is *G-code*. Bambu Studio and OrcaSlicer are slicers. This project does not write G-code. It writes the 3MF, then asks a slicer to slice it as a final check.

**FDM printing has physical limits that geometry checks must respect.** Your A1 melts plastic filament and lays it down through a 0.4 mm nozzle, one layer at a time.
- **Walls** are built from *perimeters*, each about one nozzle width. Prusa marks walls thinner than one perimeter as not printable, and walls between one and two perimeters print poorly. Exact widths depend on slicer settings, and modern slicers may widen or drop a thin wall, so it is not reproduced as designed. Rules: `fdm.wall.single_perimeter`, `fdm.wall.min_thickness`.
- **Overhangs** are surfaces that lean outward. Past roughly 45° from vertical, a layer has too little below it and sags, unless the slicer adds supports. Rule: `fdm.overhang.max_angle`.
- **Bridges** are flat spans between two supports. They can cross only short gaps. Rule: `fdm.bridge.max_length`.
- **Clearances** are gaps between parts that must move or fit together. They are absolute: a 0.5 mm gap must stay 0.5 mm when you scale the model.
- **The first layer** is squashed slightly wider than designed ("elephant foot"). Small gaps near the bed can fuse.

**AMS lite gives your A1 up to four filaments.** A multicolor print swaps filament during the print, which costs time and some purged plastic each time. So the number of colors *per layer* matters as well as the total. Bambu says not to feed TPU, TPE, PVA or fibre-filled filaments through the AMS lite; those print from an external spool.

## How a print fails, and what catches it

| Failure | Example | Caught by |
|---|---|---|
| Broken file geometry | holes, non-manifold edges, inside-out triangles | the validation gate, before export |
| Geometry the printer cannot make | walls thinner than a perimeter, long bridges, too big for the bed | the gate, using rules and your printer profile |
| Slicer rejects or misreads the file | too many triangles, colors lost on import | a headless slicer run at the end |
| Physics on your machine | joints fuse, holes print undersized | calibration prints on your A1, recorded in its profile |
